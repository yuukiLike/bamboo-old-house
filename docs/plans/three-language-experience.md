# 四时竹声：三语实现与验收

2026-09-28。已按作者最终决定实现：中文保留原叙事；英文采用莎士比亚式创作；日文采用物哀表达，并保留井旁雨景的改稿。正文与核对说明见[三语文稿](../content/three-language-narrative.md)。

## 技术选择

沿用现有 **vinext / Vite + React + TypeScript + Three.js**。三种固定语言使用类型化本地内容文件；运行时没有翻译API、翻译后台或新增依赖。

本项目只有一个持续运行的体验组件消费文案，因此使用 `useLanguage` 保存语言状态，不增加Context层。`zh.ts` 定义完整字段形状，`en.ts`、`ja.ts` 通过 `satisfies Content` 校验字段。场景独立写作，UI使用语义键。进度只替换一个明确的数字占位符，不建立通用消息格式化引擎。

与 i18next / next-intl 比较后，当前没有复杂复数规则、翻译平台或大量语言的需求。本地类型化内容可以直接表达独立创作，也避免为这个单页3D体验增加服务端语言中间件。未来出现这些需求时可重新评估。

| 归属 | 内容 |
| --- | --- |
| `src/content/zh.ts`、`en.ts`、`ja.ts` | 页面信息、各场景、UI、错误、阶段提示和来源入口 |

| `public/audio/credits.en.md`、`credits.ja.md` | 面向访客的录音来源说明，保留原作者和链接 |

## 路径约定

| URL | 语言 | HTML lang | 导出文件 |
| --- | --- | --- | --- |
| `/` | 中文 | `zh-CN` | `dist/client/index.html` |
| `/en` | English | `en` | `dist/client/en.html` |
| `/ja` | 日本語 | `ja` | `dist/client/ja.html` |

`/en/` 和 `/ja/` 也可以访问。根路径直接是中文，不另增 `/zh`。不根据浏览器语言、Cookie或本地存储覆盖URL。未知路径返回404。

可选catch-all路由的根布局读取语言参数，令静态HTML的 `lang`、title、description、正文一致；三个入口均有hreflang链接。构建额外生成404页面，它使用中文根布局。语言链接带真实href，支持复制或新标签打开。

普通点击语言链接使用 `history.replaceState` 更新路径，并保留query、hash及框架历史状态。语言选择不额外占用后退记录；真实历史遍历仍按当前路径同步语言。刷新后通过对应静态页面恢复语言。

## 场景生命周期

语言变化只更新文字，不重新执行 `createScene`。WebGL画布、场景实例、音频上下文、当前视点、时段、天气、音量和环顾状态不因语言选择而重建。

- 场景加载回调只发送阶段ID，错误状态只保存错误ID，渲染时使用当前语言，因此加载中切换也不会被旧语言回调覆盖。
- 画布的 `setDescription` 只更新无障碍文字，与重置环顾视角的 `setActive` 分开。
- 进度通过当前语言的文本引用更新，不因文案变化重建滚动效果。
- 地点、天气和章节的几何配置只保留稳定ID与数值，文字从内容文件读取。

## 排版与文案核对

英文使用Baskerville / Palatino / Georgia系统衬线回退、自然词距和诗行停顿；页头用短名，主标题保留完整名称。日文使用日文衬线与无衬线字体回退，并采用禁则断行。没有新增字体下载。

桌面保留画面中的留白；手机将语言选择与时段控制分行。英文窄屏正文可自然回流，设置选项允许合理换行。井旁与林间正文在手机保留显示。极短视口允许在正文区域滚动阅读，避免用省略号截去叙事。

以 `aab8a75` 为基准核对47项中文叙事字段。英日文已完成助手自审；未开展独立母语编辑审校或读者研究。来源页明确录音并非老家现场采集。`?perf=1&perfUI=1` 开启的开发诊断面板仍保留原中文，不属于公开体验文案。
