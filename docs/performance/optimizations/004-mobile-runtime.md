# 检测生命周期与画质配置

2026-09-26，父版本 `8a9033d`，交付版本 `c24ca12`。

## 改动

- 面板刷新从每秒 4 次改为 1 次，按需派生时间线和资源摘要。
- 新增“停止检测”：停止诊断 RAF、观察器、监听器、业务计时与 UI 刷新，保留最终记录供导出；场景与声音继续运行。
- 提供 30 / 60 / 跟随屏幕的画面更新上限，默认 60；动画使用实际经过时间。
- 移动端默认 DPR 上限由 1.0625 提高至 1.5，另可选择 2.0 或旧档。清晰度与更新频率独立配置。

## 数据

桌面 Canary，402 × 874 CSS 像素、设备 DPR 3：

| 配置 / 指标 | 前 | 后 | 增减 |
| --- | ---: | ---: | ---: |
| 默认绘制尺寸 | 427 × 928 | 603 × 1311 | 像素约 +99% |
| 面板刷新频率 | 4 次/秒 | 1 次/秒 | −75% |
| 后版检测停止前 → 后：定时器 / RAF / 观察器 | 1 / 1 / 2 | 0 / 0 / 0 | 全部停止 |
| 约 75 秒观察末尾 GC 后 JS 堆 | 49.49 MB | 50.14 MB | +0.65 MB |

声音解码容量前后均为 90,687,280 字节。录音循环未重复解码，采集历史有容量上限。两轮观察条件不同，用于资源与功能检查，不计算整体 FPS 收益。

30 帧会降低运动连续性；60 帧会限制高刷新率上限。默认清晰度提高会增加像素负担；配置由用户选择，不自动降档。面板 RAF Hz 表示浏览器回调率。
