# 静止画面按需绘制

2026-09-26，父版本 `e23daec`，随 `71917cc` 交付。

## 改动

“静止观看”或系统减少动态下，相机、天气、昼夜与后处理全部稳定后跳过重复 GL 绘制。输入变化、resize、转场、海报导出或未完成的 AO 细化会继续绘制；恢复动画沿用原帧率与完整效果。

CPU 更新与 RAF 继续处理交互、声音和诊断。RAF Hz 表示回调率；静止后应用绘制计数为 0，不代表浏览器停止回调。
