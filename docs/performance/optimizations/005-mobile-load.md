# 音频、竹叶缓存与 resize

2026-09-26，父版本 `c24ca12`，交付版本 `e23daec`。

## 改动

- 移动设备共用串行音频解码队列；静音或隐藏时停止调度、暂停音频上下文，再开声复用缓冲。
- 实例化植被用常量替代两个固定遮雨属性，为 28 组竹叶启用每实例风场缓存；输入不足时保留原解析着色器。
- 合并同一帧的 resize，尺寸与 DPR 相同时跳过缓冲重设。
- 停止检测后可“清空并重启”；新会话隔离旧异步回调，不回填旧导航和资源。

## 数据

Apple M4、桌面 Canary 156，402 × 874 CSS 像素、设备 DPR 3：

| 指标 | 前 | 后 | 增减 |
| --- | ---: | ---: | ---: |
| 移动路径音频最大并发解码 | 8 | 1 | −7 |
| 全部 9 段录音的 PCM 容量 | 164.48 MiB | 164.48 MiB | 0 |
| 同尺寸 30 次 resize 的画布重设 | 原逻辑重复重设 | 0 次 | 避免重复工作 |

串行解码减少并发，不减少最终 PCM 驻留，也不保证首次声音更快就绪。持续播放 90 秒未再次解码；缓冲容量保持不变。

竹叶缓存与原公式的数值误差小于 `1e-6`；建筑遮雨属性哈希与父版一致。短 GPU 采样未形成受控前后对照，整体帧率收益待复测。
