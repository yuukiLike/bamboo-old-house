## iPhone 数据字段复核

递归审查了 `docs/` 的 22 个 JSON，约 49,000 个节点、6,691 个字符串值和 733 种键名，并人工核对标识符与数值语义。

- 未发现 UDID、序列号、ECID、IMEI、MAC、PID、设备账号、真实局域网 IP、GPS、私人绝对路径或实际 token / cookie / 密码 / 私钥。
- 原生进程记录只保留匿名角色和性能数字，不含其他应用的原始进程记录。`startTimeNativeTicks` 只出现于字段说明，没有实际进程启动标识。
- `camera` / `cameraWorld` 是虚拟场景坐标，不是用户地理位置。
- 保留设备型号、系统和浏览器版本、通用 GPU 名称、画布尺寸、测试时间与相对计时，供复核测试条件；它们不是设备唯一 ID。
- 源码、模型和证据文件的 SHA 用于版本与内容校验，不是设备硬件标识。标准 loopback 预览 URL 也不是用户的真实局域网地址。
- SVG 无嵌入图片、脚本或外部加载资源。原始全进程日志、系统日志、设备清单及临时探针均留在被 Git 忽略的 `outputs/`，没有纳入本次提交。
