## 已确认需求

- 支持一个专门用于截图的模式。
- 提供截图按钮，保持极简实现。
- 当前阶段只准备本地 issue 与计划。

## 动机

用户可以直接保存喜欢的竹林与老屋画面，不必手动裁掉网站控件。

## 建议范围

- 提供截图模式入口。
- 进入后隐藏叙事文字、导航、普通工具栏和界面遮罩，只保留截图与退出操作。
- 截图按钮保存当前 3D 画面的 PNG，采用当前画布分辨率。
- 进入和退出时保留当前位置、取景方向、时段、天气及声音设置。
- 支持退出按钮及 Escape；导出期间防止重复点击，失败后可重试。
- 场景尚未加载或已切换到静态备用画面时，禁用截图入口。

首版不增加滤镜、水印、自选分辨率、相册、录屏和分享功能。

## 开工前确认

- 截图是否仅包含 3D 场景，不包含任何文字？建议是。
- 截图模式是否保持当前场景交互与动画，不增加专门的冻结、镜头编辑操作？建议是。

## 建议验收标准

- [ ] 可以进入截图模式，普通界面不再遮挡取景。
- [ ] 保存的 PNG 有实际场景内容，不包含按钮和叙事文字。
- [ ] 白天、夜晚、室内画面均可正确导出。
- [ ] 从沿路漫游中途进入再退出，当前位置不跳变。
- [ ] 从环顾状态进入再退出，取景方向不被意外重置。
- [ ] 点击退出或按 Escape 可以恢复界面；一次 Escape 不同时退出环顾。
- [ ] 导出失败有可理解的提示，按钮恢复可用，不产生空白图片的成功反馈。
- [ ] 桌面与手机预览中控件可操作，原有导航和场景切换正常。

## 已查明的实现约束

- `src/components/scene/scene.ts` 已有统一的 `renderFrame()`，截图应复用这条路径，保留室内后处理效果。
- 沿路镜头依赖滚动位置与页面总高度。隐藏界面时必须保留章节布局高度，避免镜头跳动。
- `src/components/scene/view-controls.ts` 已使用 Escape 退出环顾，需要明确截图模式的事件优先级。
- 现有暂停开关不是完整冻结场景的开关；截图首版无需扩展其语义。
